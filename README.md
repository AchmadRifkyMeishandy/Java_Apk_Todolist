# Aplikasi To-Do List Sederhana — Java

Program berbasis console untuk latihan mengelola daftar tugas menggunakan array, perulangan, dan method.

## Fitur yang Dipelajari

- Menampilkan daftar tugas.
- Menambahkan tugas.
- Menghapus tugas berdasarkan nomor.
- Memperbesar kapasitas array ketika daftar penuh.
- Memisahkan logika program ke dalam method.

## Teknologi

- Java
- JDK
- IDE Java atau terminal

## Menjalankan

Pastikan JDK sudah terpasang, kemudian jalankan `src/AplikasiTodolist.java` dari IDE. Atau gunakan terminal:

```bash
javac -d out src/AplikasiTodolist.java
java -cp out AplikasiTodolist
```

## Batasan

Data tugas disimpan di memori dan akan hilang ketika program ditutup. Penyimpanan ke file atau database dapat dijadikan pengembangan berikutnya. Repository ini berfokus pada pembelajaran logika, array, dan method.
